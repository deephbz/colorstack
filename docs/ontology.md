# Colorstack ontology

Colorstack has one central boundary: **authored intent** versus **derived
payload**. The code is authoritative for behavior; this document explains the
stable concepts and boundaries.

## Authored

A `Palette` is the human choice: surface family, intent hues, and contrast
floors. It has no target paths, application token names, ANSI indices, or
configuration syntax.

## Derived

A `Theme` resolves one Palette against one surface into ANSI slots and UI roles.
Every application payload is then rendered from that Theme. A generated hex is
not a second source of color truth.

## Ownership

`Layer` uses a closed ownership vocabulary:

- `GENERATED` is a complete Colorstack payload file.
- `INCLUDE` is an application-owned file that may point at a generated payload;
  Colorstack emits no bytes for it.
- `REGION` is a named payload intended for a user-managed region in a shared
  application config.

The public generator produces payloads and a SHA-256 manifest only. It does not
splice regions, inspect existing config, or infer installation targets.

## Verbs

- `repair(color, bg, floor)` moves a color away from the surface in OKLab until
  it reaches a contrast floor.
- `soften(color, bg, ceiling)` moves a color toward the surface until it stays
  below a comfort ceiling.
- `repair_on(color, surfaces, floor)` repairs against every surface a role is
  drawn on; the strictest surface wins.
- `build(palette, ink_contrast)` creates a Theme. It solves surfaces first:
  selection and alt tiers are softened under the panel ceiling, and tool
  panels are tinted from the accents. It then repairs every foreground on
  every surface in `Theme.surfaces`.

OKLCH encoding reduces chroma to the sRGB gamut at fixed lightness and hue.
A per-channel clamp would move the hue.
- `gen.py` renders a fresh output bundle at an explicit path.
- `switch.py` atomically replaces only an explicit bundle that an existing
  manifest proves Colorstack owns.

The resulting manifest is provenance for generated bytes, not evidence that an
application is using them.
